# 五篇 Zotero `survey` 论文的结构深度拆解

**目的：** 针对 Zotero `survey` 收藏中的 5 篇综述，逐一理解其 (a) 章节规划、(b) 格式/发表载体、(c) 图与表的安排，以便为我们的《人像风格迁移综述：2015–2025 十年回顾》借鉴成熟的结构范式。

数据来源为开放获取全文（arXiv ar5iv / HTML、MDPI、IJCV、Elsevier 摘要片段）。第 2 篇（MDPI）被反爬封锁（HTTP 403），其形态依据 DOI/载体推断并标注。

---

## 1. Personalized Image Generation with Deep Generative Models: A Decade Survey
**Wei, Zheng, Zhang, Liu, Ji, Zhang, Zuo** — arXiv:2502.13081（CVM 2025，39 页）。`zhang2025personalized`

- **格式：** 期刊 *Review Article*（Computational Visual Media），**单栏**，约 39 页，覆盖 300+ 方法。
- **章节规划**
  1. 引言  *(图 1：按范式配色的论文数量增长时间线；图 2：综述组织 taxonomy 树)*
  2. 问题定义与预备知识  *(2.1 问题定义；2.2 生成模型 → GAN / 文生图扩散 / 多模态自回归)*  *(图 3 生成模型示意；图 4 自回归模型)*
  3. 基于 **GAN** 的个性化图像生成  *(3.1 总览；3.2 反演空间；3.3 GAN 反演方法 [优化/学习/混合]；3.4 隐空间编辑 [导航/文本驱动])*
  4. 基于 **DM（扩散模型）** 的个性化图像生成  *(4.1 总览；4.2 反演空间；4.3 概念反演 [免训练/优化/学习/混合]；4.4 个性化生成 [主体/人脸/角色/风格/高层语义/多概念]；4.5 文本驱动编辑)*
  5. 基于 **AR（自回归）** 的个性化图像生成
  6. 评估  *(6.1 数据集；6.2 指标 [概念保真度 / 文本可编辑性 / 主观评价])*
  7. 挑战与未来方向  *(5 个分轴)*
  8. 结论
- **图/表：** 4+ 图（增长时间线、作为全文主线的 **taxonomy 树**、模型示意）。各方法族配对比/taxonomy 表。
- **标志性手法：** 一个 **统一框架**（概念反演 + 个性化 = 3 个组件：*反演空间 / 反演方法 / 个性化方案*）**驱动整套按生成模型组织的章节**，外加一张 **taxonomy 树图作为论文骨架**。

## 2. Style Transfer Review: Traditional Machine Learning to Deep Learning
**Xu, Xia, Hu, Zhou, Weng** — Information（MDPI）2025，16(2):157，DOI 10.3390/info16020157。`xu2025stylereview`

- **格式：** MDPI *Information*，**单栏**，开放获取，2025。（全文被反爬封锁，HTTP 403；结构依据载体惯例 + 摘要推断。）
- **推测章节规划**（MDPI 综述惯例）：引言 → 传统 / 预深度学习风格迁移 → 深度学习（CNN/GAN/Diffusion）风格迁移 → 应用 → 挑战/未来。
- **图/表：** 典型 MDPI 综述含 5–15 图（流水线图、taxonomy 图）及 2–5 张汇总表。
- **标志性手法（推测）：** 一条 **从历史/时代演进的弧线**（从经典 ML 到深度学习）——即以"时代"而非"生成模型族"为主轴。
- **使用提示：** 章节划分暂作推测，待在 Zotero 中打开 PDF 确认；`references.bib` 中的引文元数据已核验无误。

## 4. Image neural style transfer: A review

- **格式：** 期刊（Elsevier），**双栏**，2023，57 篇参考文献。
- **章节规划**（来自 ScienceDirect 片段）：引言 *(图 1：以图展示领域划分为"前 CNN"与"神经"两类)* → "非神经网络风格迁移" → 以 **GAN 为透镜** 回顾 CNN/神经风格迁移（原理细节、优缺点、性能评估）→ 未来方向。
- **图/表：** 图 1（分类示意）；ScienceDirect 列有独立的 *Figures* 与 *Tables* 区。

- **章节规划**

  3. 3D 神经风格化  *(3.1 分类法；3.2 基于 Mesh [几何形变/纹理]；3.3 基于神经场 [前馈 / 优化图像引导 / 文本引导]；3.4 体素；3.5 点云；3.6 隐式形状编辑；3.7 实践指南)*
  4. 数据集与评估  *(4.1 数据集；4.2 准则/指标；4.3 基准 [设置/讨论])*
  5. 应用  *(5.1–5.5 资产设计 / 虚拟形象 / 非真实感绘制 / PBR / 工业)*

- **标志性手法：** (a) **按 3D 表示组织的分类法**（mesh/场/体素/点云）；(b) 正式 **Definition 框**；(c) 给出可操作建议的 **"实践指南"小节**；(d) **带实验的真实基准**；(e) 独立的 **应用** 章节；(f) **沿 5 个命名轴组织的挑战**。
